This module stands up a GCS bucket that's locked down from the start, not left as follow-up work. It creates its own KMS key ring and crypto key, so key establishment belongs to us (User / Client managed) rather than Google's default (SC-12), rotates that key every 90 days (SC-13), and encrypts the bucket at rest with it (SC-28). Objects sit behind a retention policy so they can't be deleted before the configured window closes (AU-11). Required labels (project, environment, managed_by, compliance_scope) are merged onto every bucket and can't be overwritten by whatever labels a caller passes in (CM-6). Uniform bucket-level access is on and public access prevention is enforced, so the bucket can never be opened to the internet (AC-3).
